星 穹
Celest · 无窗体星图 UI 库
v1.3 · 电脑 + 手机通用

不依赖任何 UI 库。三级同心星环：第1环 = 主侧边栏（大类）→ 第2环 = 副侧边栏（子类，一个主栏可挂多个）→ 第3环起 = 功能星；前两环都是分类，第三环才是功能。某副栏功能多则自动再向外多开几环。
本版要点：三级星环（主侧边栏 / 副侧边栏 / 功能） · 开关点空白不再丢失 · 内置纯矢量图标（不依赖字体） · 下拉框 / 按钮 · 搜索支持键盘操作。

2 · 快速开始（最小可运行示例）

local Celest = loadstring(game:HttpGet(
	"https://raw.githubusercontent.com/LaPlua/Lua5.1/main/Celest.lua"))()

local win = Celest.new({
	title    = "星 穹",
	subtitle = "C E L E S T",
})

-- 第1环 · 主侧边栏（大类），glyph 用内置图标名，见第 5 节
local combat = win:Category("兵戈", "sword")
-- 第2环 · 副侧边栏（子类），一个主栏可挂多个
local aim  = combat:Category("瞄准", "target")
local arms = combat:Category("武备", "shield")

-- 第3环起 · 功能星，挂在副栏上
aim:Toggle("自动瞄准", false, function(on) print("自动瞄准", on) end)
aim:Slider("视野半径", 0, 100, 50, function(v) print("半径", v) end)
aim:Dropdown("瞄准部位", { "头部", "胸部" }, "头部", function(v) print("部位", v) end)
arms:Button("执行一次", function() print("bang") end)

运行后：电脑按 ALT 呼出星图（再按归寂），手机点右下角常驻星点呼出。

5 · 分类 Category（主侧边栏 / 副侧边栏）

Celest 的分类分两级，各占一圈星环，功能挂在第二级上：

  • win:Category(name, glyph) —— 创建 主侧边栏（第1环 · 大类）；
  • 主栏:Category(name, glyph) —— 在该主栏下创建 副侧边栏（第2环 · 子类），一个主栏可以挂多个副栏；
  • 功能控件（Toggle / Slider / Button / Dropdown）挂在 副栏 上，显示为 功能星环（第3环起）。
参数类型说明
namestring名称（显示在所属星环的星点下方）
glyphstring星点上的标记：传内置图标名则用矢量图标绘制；传其它字符则直接显示该字符。默认 "✦"
-- 第1环 · 主侧边栏（大类）
local combat = win:Category("兵戈", "sword")
local visual = win:Category("观照", "eye")

-- 第2环 · 副侧边栏（子类）：同一个主栏可挂多个副栏
local aim  = combat:Category("瞄准", "target")
local arms = combat:Category("武备", "shield")

-- 第3环起 · 功能星，挂在副栏上
aim:Toggle("自动瞄准", false, function(on) print(on) end)
arms:Slider("平滑阻尼", 0, 100, 35, function(v) print(v) end)
点第1环星点 → 切换主栏（副栏自动回到第一个）；点第2环星点 → 切换副栏，第3环起的功能星随之整圈换成该副栏的功能。
兼容写法：直接往主栏上挂控件（如 combat:Toggle(...)）也可以，Celest 会自动为该主栏建一个名为「常规」的副栏来接住这些功能。

内置图标名一览（运行时可用 Celest.IconNames 打印完整列表，Celest.Icons 取绘制函数）：

dot      sword    shield   eye      target   crosshair  bolt
gear     layers   search   star     run      wave       list
check    lock     power    plus     box      flag       home
info     warn     sound    code     text     radar

图标全部由 Frame + UIStroke 现场绘制，不使用任何字体或图片资源。

6 · 控件详解

所有控件挂在副侧边栏对象上，按调用顺序排布到该副栏的功能星环（第3环起）。

6.1Toggle 开关

local t = aim:Toggle("自动瞄准", false, function(on)
	print("自动瞄准 ->", on)
end)
参数类型说明
namestring功能名（星点下方文字）
defaultboolean初始状态，省略为 false
cbfunctioncb(on)，点击切换时触发

返回 item：{ kind = "toggle", name, value, cb }，用 t.value 读当前状态。

6.2Slider 数值

local s = aim:Slider("视野半径", 0, 100, 50, function(v)
	print("半径 ->", v)
end)
参数类型说明
namestring功能名
min / maxnumber范围，省略为 0 / 100
defaultnumber初始值，省略取 min
cbfunctioncb(v)，拖动时实时触发

返回 item：{ kind = "slider", name, min, max, value, cb }。
操作：先单击数值星选中，再按住左右拖动调值。

6.3Button 按钮点一次就执行

arms:Button("执行一次", function()
	print("bang")
end)
参数类型说明
namestring按钮名
cbfunction点击时触发一次

返回 item：{ kind = "button", name, cb }。星点上带一个箭头标记，点一下执行一次。

6.4Dropdown 下拉框新增

local d = arms:Dropdown("作战模式", { "平衡", "激进", "潜行" }, "平衡", function(v)
	print("作战模式 ->", v)
end)
参数类型说明
namestring功能名
optionstable字符串数组，所有可选项
defaultstring初始选中项；省略取 options[1]
cbfunctioncb(v)，选中某一项时触发，v 为该项

返回 item：{ kind = "dropdown", name, options, value, cb }，用 d.value 读当前选项。
操作：点该下拉星展开列表（列表靠近星点弹出并自动避让屏幕边缘）→ 点其中一项选中；选中项左侧有高亮标记。点空白处即可收起列表。

7 · 三级星环布局

Celest 把「侧边栏」做成了三级同心的星环：前两环都是分类，第三环起才是功能。

  • 主侧边栏（第1环） —— 放大类星点，相当于一级菜单，负责「选哪个大类」；
  • 副侧边栏（第2环） —— 放当前主栏下的子类星点，相当于二级菜单。一个主侧边栏可以挂多个副侧边栏，切换主栏时整圈副栏随之换成该主栏的子类；
  • 功能星环（第3环起） —— 放当前副栏的功能星（开关 / 数值 / 下拉 / 按钮）。某个副栏的功能超过 PER_RING = 8 个时，会再向外自动多开一环（第4、5…环），这些环仍然属于该副栏。
常量值含义
PER_RING8每个功能星环最多放几个功能星
R_PRIMARY130主侧边栏（第1环 · 大类）半径
R_SUB226副侧边栏（第2环 · 子类）半径
R_FUNC332功能星环（第3环 · 功能）首环半径
STEP_R104功能星各环之间的间距
术语对照：
第1环 = 主侧边栏 = 大类 = 一级菜单；
第2环 = 副侧边栏 = 子类 = 二级菜单（一个主栏可挂多个）；
第3环起 = 功能星环 = 挂在副栏下的具体功能。

三级星环已整体向中心收拢，四周留白更大；星图整体按视口自动缩放（电脑 / 手机自适应），无需手动处理分辨率。

8 · 运行时控制 API

方法说明
win:Open()展开星图
win:Close()收合星图（右下角常驻星点仍在）
win:Search(prefill)打开「搜索」搜索面板，可预填关键字
win:Select(name)按主侧边栏名切换（副侧边栏自动回到第一个）
win:Destroy()销毁整个 UI 并断开连接
print(Celest.Version)                -- 版本号
print(Celest.IconNames)              -- 全部内置图标名（数组）
win:Select("观照")                    -- 切到主侧边栏「观照」（副栏回到第一个）
win:Search("描边")                    -- 打开搜索并预填「描边」
task.delay(3, function() win:Close() end)

8.1搜索面板

打开方式：CTRL + K，或点左上角「搜索」按钮；也可 win:Search(prefill) 预填关键字。

  • 搜索范围：全部主侧边栏 / 副侧边栏下所有功能名 + 主栏名 + 副栏名，输入即时过滤；
  • 结果列表：可滚动，每行左侧是类型图标，中间功能名，右侧「主侧边栏 / 副侧边栏 · 当前状态」（如「兵戈 / 瞄准 · 62 / 100」）；
  • 键盘：↑ ↓（或 W S）移动高亮，Enter 执行，ESC 关闭；也可鼠标点；
  • 执行行为：开关 → 就地切换并保持面板打开；按钮 → 立即执行一次；下拉 → 关闭面板并展开该下拉星；数值 → 关闭面板并选中该数值星，随后可拖动调值。

9 · 主题自定义

主题字段可通过 Celest.new({ theme = { ... } }) 覆盖。常用字段：

字段说明
void遮罩底色
panel面板 / 星点底
nebA nebB nebC星云三色
star星辰白
accent accent2强调色 / 渐变尾色
line环线与描边色
dim次级文字色
local win = Celest.new({
	theme = {
		accent = Color3.fromRGB(120, 200, 255),
		line   = Color3.fromRGB(120, 200, 255),
		star   = Color3.fromRGB(235, 245, 255),
	},
})
只改强调色时，直接用 accent = ... 更省事，它会同时覆盖 accent、accent2、line。

11 · 常见问题

Q：关环后还有元素挡住游戏界面？

库已做分层处理：关环时「星场」「星云」「品牌/提示文字」「全屏拦截层」会一并隐藏，不再拦截点击。若仍被遮挡，检查是否有其它更高 DisplayOrder 的 ScreenGui。

Q：文字发虚 / 模糊？

星图容器使用普通 Frame + UIScale（非 CanvasGroup），文字为矢量渲染，缩放时保持清晰。

Q：手机点右下角没反应？

确认执行器 UserInputService.TouchEnabled 为真；星图会按触摸设备自动启用触屏拖动逻辑。

Q：想启动就展开星图？

建完界面后自行调用 win:Open()。

Q：数值星拖不动？

数值星需要先单击选中（星点变亮），再按住左右拖动；松手不移动仍视为一次选中。

Q：主侧边栏、副侧边栏、功能星分别在哪一环？

第1环 = 主侧边栏（大类）；第2环 = 副侧边栏（子类，一个主栏可挂多个副栏）；第3环起 = 功能星。前两环都是分类，第三环起才是功能。

Q：副侧边栏是什么？和主侧边栏什么关系？

副侧边栏也是分类：主侧边栏是大类（一级菜单），副侧边栏是这个主栏下的子类（二级菜单）。一个主侧边栏可以挂多个副侧边栏，功能控件挂在副栏上、显示在第3环起的功能星环。点第1环切主栏、点第2环切副栏，功能星整圈随之更换。

Q：某一类功能太多挤在一起？

第1、2环按星点数量均分 360°，建议主栏 3 ~ 6 个、每主栏下副栏 2 ~ 6 个；单个副栏功能超过 8 个时会自动向外多开一环，仍属于该副栏。功能极多时也可用搜索（CTRL + K）直达。

Q：开关点开之后，点别的地方会不会被关掉？

不会。开关状态只由点这颗功能星改变；点空白处仅取消选中 / 收起下拉，星图也不会因此关闭。ALT 也改成了切换式（按一次开、再按关）。

Q：那我想关掉菜单，怎么关才不会连功能一起关掉？

三种关法任选，都只关菜单、绝不碰开关状态：再按一次 ALT、按 ESC、或点右下角常驻星点。

Q：图标显示成方框或乱码？

把 Category 的 glyph 换成内置图标名（如 "sword"、"eye"、"gear"）即可，图标全部由 Frame + UIStroke 绘制，不依赖系统字体。可用 Celest.IconNames 查看全部名称。

Q：怎么加下拉框和「点一次就执行」的按钮？ 
cat:Dropdown("作战模式", { "平衡", "激进", "潜行" }, "平衡", function(v) print(v) end)
cat:Button("执行一次", function() print("bang") end)

下拉星点开列表选择；按钮星点一下执行一次。也可以在「搜索」搜索里直接搜到并执行。

Q：搜索好用吗？支持键盘吗？

支持。CTRL + K 打开后，↑ ↓ 选择、Enter 执行、ESC 关闭；结果可滚动，并显示每项的类型与当前状态。详见 8.1。

Q：想彻底移除 UI？

win:Destroy()
